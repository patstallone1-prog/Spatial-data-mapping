# SF Corridor 3D Seed

The first external-imagery seed catalog is generated by:

```bash
.venv/bin/python scripts/ingest_sf_corridor.py --provider panoramax --max-sequences 0
.venv/bin/python scripts/ingest_sf_corridor.py --provider kartaview --max-sequences 3 --out data/sf_corridor_kartaview_probe
.venv/bin/python scripts/merge_sf_corridor_catalogs.py data/sf_corridor data/sf_corridor_kartaview_probe --out data/sf_corridor
.venv/bin/python scripts/audit_sf_corridor.py data/sf_corridor
.venv/bin/python scripts/build_sf_corridor_3d.py --catalog data/sf_corridor --out docs/sf-corridor-3d.html
```

The interactive map is published at `docs/sf-corridor-3d.html` for GitHub Pages.
It renders the requested contiguous San Francisco region with:

- district bands for Marina, Cow Hollow, Russian Hill, North Beach, Chinatown,
  and Financial District / Downtown;
- OSM street, sidewalk, crossing, and building-footprint context;
- coverage-gated 3D building massing from OSM heights, OSM levels, or
  conservative inferred defaults when OSM has no height;
- coverage-gated curb/sidewalk/crossing bands as the visible reconstruction
  scaffold;
- H3 coverage cells scored from the catalog;
- provider observation markers and ordered sequence paths.

The current dense seed is backed by Panoramax and a bounded KartaView probe:
1,628 observations, 1,619 eligible, 19 sequences, 171 H3 coverage cells, and
249 KartaView perspective frames. The rendered OSM layer contains 15,982
building footprints; 4,652 covered buildings are promoted into 3D. The source
imagery is not committed.

Curb height is not yet an exact measured value in this artifact. Exact curb
height requires the next computer-vision/depth stage to estimate metric curb
rise from the provider imagery or Meta Glasses captures and write it back as
Kerbside-derived geometry.
