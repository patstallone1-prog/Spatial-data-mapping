02 · Measured against known truth

Where accuracy stands

The reference index only anchors captures taken from its own vantage.

With real feature matching, a survey driven from the roadway anchors roadway captures to 34 mm and footway captures not at all — zero of fifteen. Surveying the footway instead anchors the same wearer captures to 11 mm. The simulation oracle is blind to this, because it never looks at pixels. It is the sharpest architectural finding so far: the RTK rig bootstraps the index, but it has to walk the footway as well as drive the lane.

Two caveats sit on the geometry figures. Survivorship bias: with 40–80% of frames anchoring, the ones that survive are the ones with good geometry, so accuracy on survivors flatters what full coverage would give. And the texture is synthetic — procedural surface detail was itself defeating the ratio test until it was rebuilt with five decorrelated octaves, which raised rig-to-rig matches at six metres from 12 to 22. Synthetic texture validating a real matcher is close to circular. Only photographs settle it.

03 · Build state

What is finished, and what is not

Working end to end

  • DoneSimulated world — hierarchical kerb, ramp and defect distributions with modelled non-compliance
  • DoneRenderer — world-anchored surface detail, buildings, exact ground truth
  • DoneCapture trigger — distance-gated, verified against varying gait
  • DoneFrame store — content-addressed, idempotent, expiring
  • DoneRTK seeding — the bootstrap for the reference index
  • DonePose solving — PnP, RANSAC, covariance
  • DoneMetric scale — five-source fusion, disagreement flagged not averaged
  • DoneMeasurement extraction — kerb, width, cross slope with uncertainty
  • DoneStreet overlay — snapping, stable feature identity, shared map frame
  • DoneReal feature matching — SIFT/ORB, ratio, mutual and epipolar filters. Licence-clean.
  • DoneSix keyless APIs — Overpass, Nominatim, Project Sidewalk, Overture, OpenFreeMap, RTK2go

Blocking the real-world claim

  • OpenReal photographs — nothing has yet touched one. The calibration harness is built and waiting for a folder of corner pairs.
  • NextLearned matching — ALIKED + LightGlue, which should survive the vantage gap that defeats SIFT
  • NextDescriptors — MegaLoc, replacing the tiny-image baseline
  • NextFootway survey pass — the index needs both vantages, not just the driven one
  • NextSfM — GLUEMAP per cell cluster
  • NextSemantics — kerb-ramp detector, surface segmentation, sign OCR

Integration, well understood

  • PendingMeta toolkit bindings — live device and Mock Device Kit
  • PendingCARLA asset import — needs an Unreal source build
  • PendingOn-device redaction — EgoBlur, Apache 2.0, drop-in
  • PendingServer — ingest endpoint, PostGIS schema, coverage service
  • PendingGround-truth checker — the types exist; the service that runs it every release does not
  • PendingDistribution — robot API, consumer app, OpenSidewalks export

Verified this pass

  • FixedTilted plane spanning both surfaces — a 2% tilt across ten metres out-voted both real surfaces
  • FixedBuilding facade winning the footway fit — 1500 inliers against 252, then reporting zero width

  • FixedKerb hint subtracting the observer's own offset
  • Fixednp.cross on 2-D vectors, removed in NumPy 2
  • FixedRepetitive procedural texture defeating Lowe's ratio test
